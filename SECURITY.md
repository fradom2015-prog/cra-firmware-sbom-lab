# Politica di sicurezza

## Segnalare una vulnerabilità

Se trovi un problema di sicurezza negli strumenti di questo repository, segnalalo in privato tramite
**GitHub Security Advisories**: scheda *Security* → *Report a vulnerability*
(`https://github.com/fradom2015-prog/cra-firmware-sbom-lab/security/advisories/new`).

Non aprire issue pubbliche per problemi di sicurezza.

Nella segnalazione indica, se puoi:

- la versione o il commit interessato;
- i passaggi per riprodurre il problema;
- l'impatto che ti aspetti.

## Cosa succede dopo

| Fase | Tempo indicativo |
|---|---|
| Conferma di ricezione | entro 5 giorni lavorativi |
| Prima valutazione e gravità (CVSS) | entro 10 giorni lavorativi |
| Correzione e advisory | in base alla gravità, di norma entro 90 giorni |

Chi segnala in buona fede, senza accedere a dati di terzi e senza degradare servizi, non sarà oggetto
di azioni legali. Se lo desideri, verrai citato nell'advisory.

## Versioni supportate

È supportata solo l'ultima versione sul branch `main`.
